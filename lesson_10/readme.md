# Автотесты для калькулятора и интернет-магазина (Page Object + Allure)

Этот проект содержит набор UI-автотестов для двух сайтов:
- [Slow Calculator](https://bonigarcia.dev/selenium-webdriver-java/slow-calculator.html)
- [SauceDemo](https://www.saucedemo.com/)

Тесты написаны с использованием паттерна **Page Object**, фреймворка **pytest** и **Selenium WebDriver**. Для формирования наглядных отчётов используется **Allure**.

---

## Требования

- Python 3.8+
- Google Chrome (последняя версия)
- Java (JRE или JDK) – требуется для работы Allure
- Установленный [Allure Commandline](https://docs.qameta.io/allure/#_installing_a_commandline) (инструкция по установке – ниже)
